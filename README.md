# cafe-landing

'앙앙 카페'의 간단한 랜딩 페이지 예제 프로젝트예요. 순수 HTML과 CSS로만 만들어서 별도의 설치나 빌드 없이 바로 열어볼 수 있어요.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 구조와 내용 (소개, 대표 메뉴, 카페 소개, 오시는 길) |
| `style.css` | 페이지 디자인과 모바일 대응 스타일 |

## 사용 방법

1. 이 레포를 내려받아요.
2. `index.html`을 브라우저에서 열어요.

## 참고

- 메뉴, 가격, 주소는 예시 내용이에요. 실제 카페 정보에 맞게 `index.html`에서 수정해서 사용해요.
